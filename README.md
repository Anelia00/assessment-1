# Web Development II – Assessment 1

This repository contains both projects completed for Web Development II Assessment 1.

## Task 1 – Layout in React

A recreation of the Erased Tapes Records blog layout using React components and CSS.

Folder: `task-1-layout-in-react`

## Task 2 – Responsive Layouts

A recreation of the watch.it movie website using React and responsive CSS for mobile, tablet and desktop.

Folder: `task-2-responsive-layouts`

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## How to Run

Each task is a separate React project.

1. Open the folder for the task you want to run.
2. Run `npm install` in that folder.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

Each task also has its own README with more details.
