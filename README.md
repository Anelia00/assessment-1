# Erased Tapes Records - React Layout

## Project Overview

This project was developed as part of **Web Development II - Task 1: Layout in React**.

The aim of this assessment was to recreate a responsive blog webpage about the independent music label **Erased Tapes Records**, following the provided desktop wireframe and design specifications.

The website was built using React, JavaScript, HTML, and CSS.

## Technologies Used

- **React** – Building reusable components
- **JavaScript (JSX)** – Creating and organising the page structure
- **CSS3** – Styling, layouts, and responsive design
- **Vite** – Development environment and build tool
- **Git & GitHub** – Version control and project hosting

## Website Features

The webpage includes:

- Header with the Erased Tapes logo and navigation links
- Blog article with a title, introduction, and three-column text layout
- Album gallery featuring five album images
- Author section with a circular profile picture and social media links
- Comments section displaying reader feedback
- Footer containing navigation links, copyright information, and social media icons
- Responsive layouts for desktop, tablet, and mobile screens

## React Components

The website is organised into reusable React components:

- `Header` – Website logo and navigation
- `NavLinks` – Navigation links
- `Article` – Blog article content
- `AlbumGrid` – Album image gallery
- `Author` – Author biography and profile picture
- `Comments` – Reader comments
- `SocialIcons` – Social media links
- `Footer` – Footer navigation and information

Each component has its own styling file to keep the code organised and maintainable.

## Design Requirements

The implementation follows the assessment specifications:

- Page background: `#e9e9e9`
- Content background: `#ffffff`
- Footer background: `#14181d`
- Logo and author image: `200px`
- Social media icons: `50px`
- Standard spacing: `50px`
- Social media icon spacing: `10px`
- Heading font: **Protest Guerrilla**
- Body font: **Josefin Sans**

Both fonts are imported from Google Fonts.

## How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/Anelia00/task-1-layout-in-react.git
```

**2. Open the project folder**

```bash
cd task-1-layout-in-react
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL displayed in the terminal**, usually:

`http://localhost:5173/`

Node.js and npm must be installed before running the project.

## Responsive Design

The website uses CSS Flexbox, Grid, and media queries to adapt its layout to different screen sizes.

The desktop layout follows the supplied wireframe, while the tablet and mobile layouts have been adapted to maintain readability and usability.
